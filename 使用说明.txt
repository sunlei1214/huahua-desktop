华华和熙熙 · 桌面灵感搭子  v1.1

【怎么打开】
双击 华华.exe。
如果没有 exe，双击 启动华华.bat（需要 Python 3.10+）。

【两个角色】
· 华华：温柔小织女，桃粉披帛、青绿裙子，抱着小金梭。
· 熙熙：元气小胖墩，细银眼镜、珊瑚橘卫衣，抱着奶油白长耳兔。
· 右键 → 设置 → 桌宠外观 → 角色，点卡片切换，保存并应用。
· 切换后托盘图标、对话头像、名字和性格一起变。

【怎么用】
· 单击桌宠 → 打开对话框（顺手摸头 / 戳肚子）。
· 双击桌宠 → 打开对话并打招呼。
· 右键桌宠 → 让华华干活 / 大小、截图、专注、设置、退出。
· 对话框顶部四个标签：对话 / 生图 / 图生图 / 数字人。
· 「让华华干活…」：打开 Agent 执行窗口，用 MothX 读文件、跑命令、调工具；模型可切换，写文件和命令会先问你。
· 把图片、PDF、Word、PPT、Excel、视频拖到桌宠或对话框里，会自动识别 / 总结。
· 图片或视频生成完，桌宠旁边会出现带缩略图的气泡；点气泡回到对话。
· 图片点开可以放大、复制、另存；视频点封面用系统播放器播放。
· 输入框左下角：回形针 = 选文件，相机 = 框选屏幕提问。

【数字人视频】
视频模式需要一段 5–30 秒的正面人物视频作为参考。
没有素材时，点输入框下方的「示例数字人」，会使用内置的 AI 合成示例。
然后写口播文案，点「生成视频」。
流程：Qwen3-TTS 合成声音 → Duix-Avatar 对口型 → 生成成片。

【执行任务 / MothX Agent】
右键桌宠 →「让华华干活…」打开执行窗口。
· 后台运行 runtime\mothx.exe acp；
· 工作区只在你选择的文件夹内，默认是用户目录\桌面工作区；
· 模型可选，模式有「执行 / 只读计划 / YOLO」；YOLO 会二次确认；
· 思考等级可选「关闭 / 低 / 中 / 高」，推理过程显示在回答上方，可点「思考过程」折叠；
· 文件、图片可以直接拖进任务窗口或输入框，点附件右上角 × 可取消；
· 右上角「会话」可切回聊天，聊天右上角「任务」再切回来；
· 读文件、跑命令、调工具的过程会显示成卡片；
· 写文件 / 运行命令会弹出审批：允许一次 / 本会话允许 / 拒绝；
· 点右上角「—」最小化到桌宠；任务继续，头顶显示省略号思考气泡；
· 需要审批时，桌宠头顶会弹出多个选项气泡，直接点选即可；
· 点「停止」可以中止任务；
· 打包版已内置 MothX 运行时，发客户只需要华华.exe；源码运行才需要 runtime 文件夹。

【API】
所有模型都走模力方舟（MoArk）：
  对话 / 图片理解  DeepSeek-V4.1-Flash-1017
  生图 / 图生图    qwen-image-2.0-pro
  数字人视频        Duix-Avatar
  配音              Qwen3-TTS
默认地址 https://api.moark.com/v1。

第一次运行会尝试从同目录的 工作资料.txt 读取模力方舟 Key。
旧版“小织”的 Key、历史和设置会自动迁移到新目录。
也可以右键 → 设置 → 接口与模型 手动填写，并可以「添加」多个接口方案。

【文件放在哪】
默认：C:\Users\<你>\Pictures\华华作品
  图片 / 视频 / 音频 / 缓存
右键 → 设置 → 存储位置 可以改。

【设置里还有什么】
角色切换、桌宠大小、透明度、置顶、待机动作、散步、气泡、提示音、
开机启动、深度思考、待机睡眠、专注时长、历史清理、接口测试。

【抠图】
两套角色素材都用 pymatting 重新做了透明边缘精修，
去白边、收 1px 边、轻微羽化，并统一成 640×640。

【隐私】
API Key 用 Windows DPAPI 加密，只保存在本机。
对话历史和作品都在本机。只有你主动发送的内容会传给模力方舟。

详细说明见 README.md。
